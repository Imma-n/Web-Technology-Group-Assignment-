# BrightTech Solutions — Company Website

HTML & CSS website built for the "Practical Assignment: Company Website Using HTML & CSS" brief.

## Files
- `index.html` — Home page
- `about.html` — About Us
- `services.html` — Services
- `team.html` — Our Team
- `products.html` — Products
- `contact.html` — Contact Us (with form + Google Maps embed)
- `style.css` — All styling
- `images/` — Logo, hero graphic, team photos, product images, service icons (SVG placeholders — swap in real photos/logo before submitting)

## HTML elements demonstrated
Ordered list, unordered list, table, hyperlinks, images, email link (`mailto:`), telephone link (`tel:`), and a Google Maps link/embed — more than the 5 required.

## Before you submit
1. Replace the placeholder team photos in `images/team1.svg`–`team4.svg` with real passport photos (jpg/png), and update names/roles in `team.html`.
2. Replace `images/logo.svg` with your real BrightTech logo if you have one.
3. Update the address and map embed in `contact.html` to your actual location.
4. Update product names, images, and prices in `products.html` if you have real ones.

## Publishing to GitHub (required for submission)

1. Create a new repository on GitHub, e.g. `brighttech-solutions-website`.
2. On your computer, open a terminal in this folder and run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: BrightTech Solutions website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. On GitHub, go to **Settings → Pages**, set the source branch to `main` and folder to `/ (root)`, then save.
4. GitHub will give you a live URL like `https://<your-username>.github.io/<repo-name>/`.
5. Submit the repository link (and the Pages link, if enabled) to the designated submission platform.
