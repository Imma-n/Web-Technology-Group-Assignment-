# BrightTech Solutions — Company Website

HTML & CSS website built for the "Practical Assignment: Company Website Using HTML & CSS" brief.

## Files
- `index.html` — Home page
- `about.html` — About Us
- `services.html` — Services
- `team.html` — Our Team
- `products.html` — Products
- `contact.html` — Contact Us (with form + Google Maps embed)
- `style.css` — All styling
- `images/` — Logo, hero graphic, team photos, product images, service icons (SVG placeholders — swap in real photos/logo before submitting)

## HTML elements demonstrated
Ordered list, unordered list, table, hyperlinks, images, email link (`mailto:`), telephone link (`tel:`), and a Google Maps link/embed — more than the 5 required.
